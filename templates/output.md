# 结构模板与输出契约（Output Template）

## 一、全文结构骨架

```
【冷开场】两行，两个并置的具体事实（数字/重量/价格），零背景交代
    ↓
【第一幕】起源场景：一个年份 + 一个日常物件 + 一句没说出口的话
    ↓
【展开】双轨交替：
    - 对话轨（短句应答，"我说好"式节拍）
    - 后勤轨（长句观察：流程、账单、执行细节）
    ↓
【中段】重复短语建立秩序；物件第二次出现；一次称呼或语气的微小变化
    ↓
【转折】打破重复的那个节拍（第一次"不" / 第一次沉默的时长 / 一个被删的物件）
    ↓
【崩塌段】反高潮：身体读数代替情绪（数秒、心跳、日期），零形容词
    ↓
【结尾】回收开头意象 + 物件终章 + 清零句（≤8 字）
```

## 二、篇幅与节奏参数

| 参数 | 值 |
|------|-----|
| 单句成段比例 | ≥70% |
| 对话占比（按句数） | 20%-40% |
| 数字密度 | 每 80 字内至少 1 个具体数量/专有物件 |
| 比喻 | 全文 ≤2 个，仅冷喻 |
| 感叹号 | 0 |
| 情感形容词 | 0 |
| 段落上限 | 后勤观察段 ≤4 行，其余 ≤2 行 |

## 三、输出契约

用户未指定输出形式时，默认交付：

1. **标题**：平名词短语（"我的 + 身份 + 人名"式，或一个物件名；人名一律虚构或化名，禁止真实人名）
2. **正文**：按上述骨架与参数创作；人物、机构、事件全部为虚构或彻底化名，不得附着于可识别的真实人物
3. 不加前言后语，不解释风格，不附创作说明（除非用户要求）

**合规红线（不可协商）**：输出中禁止出现真实人名、真实明星/公众人物、可被反向识别的真实机构与事件。用户提供的素材若含真实人名，先替换为化名再创作；用户坚持使用真实人名时，停止执行并说明名誉权/隐私权风险。

用户指定平台（X / 微博 / 公众号）时的适配：
- **X/长推**：保留分段结构，一段一行，分隔线用"---"
- **公众号**：段间空行，可加一个小节分隔
- **微博**：压缩到 500 字内，只保留冷开场 + 一个物件 + 清零句

## 四、可调参数表（用户定制时询问）

| 参数 | 默认 | 可调范围 | 说明 |
|------|------|---------|------|
| 长度 | 用户指定 | 300-5000 字 | <800 字时结构骨架压缩为：冷开场→物件→转折→清零 |
| 灰度 | 极端克制 | 克制 / 极端克制 | 极端克制 = 沉默节拍更多、数字更碎 |
| 题材张力 | 高（财富/权力/名人） | 高 / 日常 | 日常题材（普通人的分手/失败）同样适用，数字换小（奶茶钱、公交卡、押金） |
| 叙述人称 | 第一人称过去时 | 一 / 三人称 | 三人称未经语料验证，需降 confidence 提示 |

## 五、质量自检输出（供 Judge 阶段使用）

每次交付成品时，内部完成 runtime.md 的快速自检清单（10 项），全部通过才输出。自检结果不展示给用户，除非用户询问或某项为 WARN。
