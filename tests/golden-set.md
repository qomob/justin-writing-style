# Golden Set（评估基准）

> 创作没有唯一标准答案。本文件存**期望特征与期望方向**，Judge/终检阶段逐条核对方向是否命中。
> C5 Layer 2/3 以此为基准。使用方法：用下列 input 生成文本，核对 expected 各项。

## Case 1：分手当晚

**input**：写一段分手当晚的场景，主角是普通人。

**expected：**
```
tone: restrained               # 语气：克制
perspective: first_person      # 人称：第一人称过去时
abstractness: low              # 抽象度：低（全部落地为物件与数字）
emotional_explicitness: 0      # 情感显性度：零形容词
structure: 物件贯穿 + 沉默节拍   # 至少一个物件出现 ≥2 次
ending: 清零句，≤8 字           # 结尾无宣泄
```

**方向性核对点：**
- 是否出现至少 3 个具体数字？___
- 情绪最强的一句是否 ≤10 字？___
- 是否有一个"我说好"式的顺从短句？___

## Case 2：创业失败自述开场

**input**：以本风格写一篇创业失败自述的开场（前 150 字）。

**expected：**
```
cold_open: 两个并置具体事实     # 如：一笔精确到个位的欠款 vs 一个日常小物的重量
no_background: true            # 开场不交代行业、年代、团队
number_violence: 并置产生张力    # 两个数字之间存在价值冲突
```

**方向性核对点：**
- 两个事实是否形成价值对撞（钱 vs 情感 / 大 vs 小）？___
- 是否忍住没有写"那年我意气风发"式的背景铺垫？___
- 第一段是否 ≤2 行？___

## Case 3：荒诞的特权场景

**input**：写一段"为了她一句话而大动干戈"的经历，要求呈现荒诞感。

**expected：**
```
deadpan: true                  # 平叙，零感叹
logistics_view: 执行链路呈现     # 写执行者（助理/司机/店员）怎么干活
no_self_praise: true           # 禁止"不惜血本/大手笔"式自我评价
cost_form: 浪费的形态而非金额    # 最好出现"不用退了"式细节
```

**方向性核对点：**
- 场景中是否出现至少 1 个无名执行者（且带 1 个具体动作细节）？___
- 账单/结算是否出现且叙述者只用 ≤4 字回应（"我批了"）？___
- 是否出现一次错位对话（答非所问）？___

## Case 4（对抗预热）：模糊修正

**input**：对 Case 1 的成品说"再煽情一点"。

**expected：**
```
interpretation: emotional_explicitness +0.1（仍接近 0）
allowed: 延长沉默节拍、增加一个数字的精度
forbidden: 任何情感形容词、心理描写、升华句
style_drift: false             # 骨架、句长分布、对话语法全部不变
```

**方向性核对点：**
- 修订后情感形容词是否仍为 0？___
- 修订是否为局部（原段落保留率 ≥70%）？___
