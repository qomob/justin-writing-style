# 结构模式库（Structure Patterns）

> Step 1 题材摄取与 Step 2 结构设计时加载。六个可组合的结构模式 + 分节大纲方法。
> 证据等级：模式归纳为 secondary；例证均为自创示意，非原文摘录。

## P1 双重量意象开场

开场用两个精确数字的意象并置，形成物理对比，承载全文主题。一个极轻、一个极重。

示范开场：

```
一支钢笔的重量，十一克。
八千万股权的重量，四页纸。
林岁在电话里向我要的是后者，签的是前者。
```

**设计方法：**
1. 从题材中找到"最轻的东西"（生命 / 一句话 / 一张照片 / 一个念头）
2. 找到"最重的东西"（钱 / 房 / 责任 / 尸体）
3. 各配一个精确物理量，两行并列，第三行点破交易关系（"抵押的是前者。""签的是前者。"）

## P2 螺旋时间线

时间结构：现在（结局状态）→ 最早过去（关系起点）→ 顺叙推进 → 回到现在（核心场景）→ 尾声。

- 开场必须落在"最贵的时刻"（钱 / 资源已投入的顶点）
- 第一次闪回用具体年份触发（如"2009年"）
- 顺叙段用物件的换代标记时间（"每换一部手机……我都把那条语音移过去。"）
- 回到现在时，读者已知道结局，重读开场获得第二层含义

## P3 分节制

用 `---` 分割时间块。每节一个叙事单元，节内时间连续，节间可跳跃数年。

示范分节逻辑：现在（最后那笔钱）| 起点（最早相识）| 初遇重逢 | 远行 | 承诺与转账 | 拒绝 | 尾声。

**执行要点：** 每节结束时留一个未闭合的物件（针线包、语音、钥匙），下一节或尾声回收。

## P4 反高潮结尾

见 style-rules.md R12。结构上的配套要求：核心问题在倒数第二节提出，最后一节只做收尾动作 + 空镜。

示范尾声的收尾动作链（全部是物理动作）：
把旧语音翻出来听了一次 → 用针线包缝了两针，不对，放回去 → 划掉日历提醒 → 重读那份合同 → 回忆某个散场的夜晚。

最后一行落空镜：

```
凌晨四点的车库，
一盏灯都没亮。
```

## P5 首尾回环

开头与结尾使用同一个短句或同一意象，语义在结尾发生翻转。

示范：开篇"已经有人替她付学费了。"（关系的起点）↔ 结尾"没有人来付这笔账。"（关系的终局）。或同一句"什么都不发生。"第一次出现是关系的性质，最后一次是关系的结局。

**执行要点：** 回环句必须逐字相同，只允许一处语法性微调（如"不"→"没有"）。

## P6 旁支人物超比例投喂

给无关紧要的旁人超过其叙事权重的细节，用旁人的尽职 / 名字 / 技艺，对照主角关系的空洞。

示范实例：
- 家政：没人住仍每天打扫整套，一个半小时，"系统里排着的。"
- 管家：自己试出柜门留缝散味，"像讨论一门手艺。"
- 关键对照句："她知道那批柜子是哪年买的。我不知道。"

**执行要点：** 每篇至少一个获得完整技艺描写的旁人（配 R8 说明性长段），以及一句"她知道……我不知道。"式对照。

## P7 他者镜子（可选）

引入一个绝对理性的第三方（AI / 律师 / 医生 / 会计），用它的"不为难"照出人的为难。

```
我把账目和事由输进去，系统说，这笔钱不应该出。
我问，她是不是不算我的朋友了。
系统说，关于友谊，我没有模型。但是这笔钱不应该出。
```

```
让我发凉的不是它算得快，是它一点犹豫都没有。
它不为难。
```

**执行要点：** 他者的建议必须冷酷正确但情感上不可执行；主角的反应是生理性的（发凉），不是辩论。

## 分节大纲方法

Step 2 输出格式（每节一行）：

```
| 节 | 时间戳 | 场景 | 回收/埋设的物件 | 重复句状态 |
|----|--------|------|------------------|-----------|
| 1 | 现在·顶点 | [一句话] | 埋：物件A | — |
| 2 | 最早过去 | [一句话] | 埋：物件B | 首次出现 |
| ... | | | | |
| N | 尾声 | [一句话] | 收：全部物件 | 已打破 |
```

行数建议：8-12 节。每节 200-600 字。
