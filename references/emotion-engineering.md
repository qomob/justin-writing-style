# 情感工程（Emotion Engineering）

> Step 3 系统配置时加载。零抒情风格的情感转译技术：把"想说的话"全部转成动作、物件、数字。
> 证据等级：技术归纳为 secondary；例证均为自创示意，非原文摘录。

## E1 情感转译表

写作前把每个情感节点翻译成物理动作。禁直述，只许转译：

| 想表达的 | 禁止写 | 应该写（示范形态） |
|----------|--------|---------------------|
| 心碎 | 我心碎了 | 把手机屏幕朝下。数了三十秒脉搏，很稳。再数一遍，还是很稳。 |
| 深爱 | 我很爱她 | 犹豫一周的八百块外套 vs 眼都不眨的八千万 |
| 不舍 | 我舍不得 | 把那条语音删了。第二天从备份里找回来了。 |
| 委屈 | 我很委屈 | 我按着自己的手腕，像个护士在给别人量脉搏。 |
| 恐惧失去 | 我怕失去她 | "等我眼睛不行了，就没人给你缝扣子了。"我笑了一下，没说话。 |
| 麻木 | 我麻木了 | 我没有哭。我一直在等我哭。 |
| 怀念 | 我想念她 | 我的大衣现在还是晃的。 |

**转译公式：** 情感 = 一次可观测的身体动作 + 一个不合比例的细节（数两遍脉搏 / 犹豫一周 / 缝四十分钟）。

## E2 载情物件系统

为题材配置 3-5 个贯穿全文的实物。合格物件四个标准：

1. **可磨损** — 有使用痕迹和方向（针线包：线要顺着原来的针脚走，我忘了是哪边）
2. **可遗失 / 可找回** — 支持删除与恢复的动作（那条语音：删了，第二天从备份里找回来）
3. **可空置** — 存在但闲置（包下的整层公寓 / 停在负二层的车 / 没拆封的合同副本）
4. **低价值高载荷** — 物件本身不值钱，承载的东西无价（糊到看不清的旧语音 vs 八千万）

**物件的三个生命周期节点：**
- 埋设（前 1/3）：作为日常细节出现，不点破
- 使用（中段）：承担一次亲密或交易场景（缝扣子的四十分钟）
- 回收（尾声）：一次失败的重逢（缝了两针，不对，放回去了）

## E3 精确数字系统

每篇 ≥10 个精确数字，覆盖四类：

| 类别 | 示范形态 | 功能 |
|------|----------|------|
| 金钱 | 八百块 / 两百万定金 / 三千七百块养护费 | 用小额反差标定大额的轻描淡写 |
| 时间 | 犹豫了一周 / 四十分钟 / 下午7:10 | 给情感称重的砝码 |
| 物理量 | 十一克 / 四页纸 / 零下二十五度 | 开场对比的原料 |
| 生理量 | 每分钟六十几下 / 抽了两管血 | 身体作为最后的测谎仪 |

**关键规则：** 数字本身不评论。让"犹豫一周买八百块外套"与"眼都不眨转八千万"自行形成审判。

## E4 空置美学

占有而不使用，是本风格表达"关系已死"的核心意象：

```
整层包下来，半个月，一百二十万，为了她不见人。她住了一晚就走了。
剩下的日子，家政每天照常上去。
```

```
和公寓一起空着的，还有辆迈巴赫停在负二层，司机每天照常来打卡。
```

```
合同的副本，三份，一直没拆封。
```

**执行要点：** 空置物的维护成本要照常发生（家政照常打扫、司机照常打卡、养护费照常出）。花钱维持一个空，比描写空虚有效一百倍。

## E5 信息不对称

主角"我"故意不知道关键信息，且不问：

```
她没有说那笔钱拿去做什么。我也没问。
我不知道是哪家诊所。我也不知道她自己去的，还是有人陪。
有些事她一直没讲。我也没有问。
```

**执行要点：** "我不知道 + 我没有问"是尊严的姿势。问题留给读者替他问。

## E6 转喻式疼痛

不写疼，写疼的邻居——方向、位置、朝向：

```
那面墙朝着江。
```

（敲掉重做的赔偿单出现了，疼的是没说的事。）

**公式：** 情感浓度最高的时刻，把镜头转向一个无生命的方位 / 物体 / 天色（"看着江面从蓝变成灰再变成白。"）。

## E7 仪式性重复动作

设计一个可重复的私人仪式，重复 2-3 次，最后一次打断：

- 示范：数脉搏（数了一遍，又数了一遍）→ 等哭（一直没等到）
- 示范：每换设备移语音（从旧手机到今天）→ 删掉 → 找回

**执行要点：** 仪式必须是单人、无声、精确计数的。

## Step 3 输出格式

```
## 三系统配置表

### 载情物件（3-5 个）
| 物件 | 埋设节 | 使用节 | 回收节 | 载荷 |
|------|--------|--------|--------|------|
| 针线包 | 3 | 4 | 8 | 亲密的方向感 |

### 精确数字（≥10 个）
| 数字 | 类别 | 出现节 | 反差对象 |
|------|------|--------|----------|
| 八百块（外套） | 金钱 | 2 | 两百万定金 |

### 顺从性重复句
- 句子：我说行。
- 重复次数与分布：节2/3/4/5/6，共 7 次
- 打破点：节 6（"我说，让我想想。"）

### 仪式动作
- 动作：数脉搏
- 重复：节 6 两次
- 打断/落空：等哭，没等到
```
