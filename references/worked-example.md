# 示范样本（Worked Example）

> Step 5 风格自检时加载，作为语感对照的基准样本。
> **版权说明：** 本文件全部片段为按风格规则**自创**的风格示意（虚构人物、虚构事件），非任何原文摘录。用于演示各条规则如何落地。

示范故事设定（虚构）：第一人称"我"，做投资的，与旧相识林岁十年的金钱往来，以一次拒付收场。

## 开场 — 双重量意象（P1 + R5）

```
一支钢笔的重量，十一克。
八千万股权的重量，四页纸。
林岁在电话里向我要的是后者，签的是前者。
```

**用了什么：** P1 双重量开场（克 vs 页）；R5 精确数字；第三行"签"一个动词完成交易结构，零情绪词。

## 时间跳跃 — 螺旋闪回（P2 + R5）

```
2009年，已经有人替她付学费了。那年我刚进公司。
当然，付钱的不是我。
```

**用了什么：** P2 用具体年份触发闪回；"当然，付钱的不是我。"单句成段的自嘲，不展开自卑，一笔带过。

```
后来这些年，我做每笔业务的时候都在想同一个问题：账户到多少，她会主动打来。
第一个一千万的时候我想过，第十个的时候我想过。
后来我不想了。那个手机号早就是空号了。
我没有换掉备注。
```

**用了什么：** R10 否定句式收束；用外部事实（空号）替代心理描写——"不想了"的真正原因是媒介死了，不是心死了。

## 对话体 — 零修饰（R2 + R3）

```
我带她去看那幅小画。她看了很久，问我，这谁的。
一个新人的，两百六十万。
她说，画歪了怎么办。
我沉默了。她说，不管了，去吃饭吧。
我说行。
```

**用了什么：** R2 对话无引号、动词只有"问/说"；天价数字（R5）当普通信息流过；"我说行。"是顺从性重复句的一次标准现身。

## 亲密场景 — 物件载情（E1 + E2 + R5）

```
她说，你大衣扣子松了，走光了。
……
她把我的袖子翻过来，一颗一颗缝。
……
我说这个要缝多久。
她说，缝到不晃为止。
五颗扣子，她缝了快四十分钟。
```

**用了什么：** 亲密完全由"缝扣子"这个物件动作承载（E1 转译）；"四十分钟"（R5）给温柔称重；无一处"温柔""体贴"类词。

```
中间她说过一句话。她说，等我眼睛不行了，就没人给你缝了。
我笑了一下，没说话。
```

**用了什么：** 老去/离开的预告藏在工具性口语里；回应是"笑了一下，没说话"（R10），不是任何情感表达。

## 悖论并置（R11）

```
她说的话我全信。
那条语音我存着，一直存到现在。
但是我一个字也不信。
```

**用了什么：** 三行完成信任悖论，中间隔了一个物理动作（存着语音），零解释。

## 空置美学（E4）

```
剩下的半个月，家政每天照常去那套公寓。……做完整套，一个半小时。
助理问她，没人住，为什么还做。
她说，系统里排着的。
```

```
和公寓一起空着的，还有辆迈巴赫停在负二层，司机每天照常来打卡。
```

**用了什么：** E4 花钱维持一个空；旁支人物（家政）获得完整细节（P6）；关系的空，由制度化的照常运转来宣判。

## 说明性长段 — 只给物（R8）

```
管家学会了一套除湿的方法。红木的柜子怕潮，雨季要垫报纸，一周换一次。
换了报纸柜门要留条缝，散味。她试过全开，木头裂了条口子，后来就只留一条缝。
这件事没人教她，是她自己试出来的。
她知道那批柜子是哪年买的。我不知道。
```

```
司机说，这车按十二个气缸设计的，常年就坐一到两个人，缸内积碳。
所以每个月要上一次高速，拉到两百，跑够四十分钟。到了地方，人再想办法回来。
```

**用了什么：** R8 长段专属"物的技术细节"（除湿方法论 / 拉高速清积碳）；结尾"她知道……我不知道。"是 P6 对照句的标准形态。

## 他者镜子（P7）

```
我把账目和事由输进去，系统说，这笔钱不应该出。
我问，她是不是不算我的朋友了。
系统说，关于友谊，我没有模型。但是这笔钱不应该出。
```

```
让我发凉的不是它算得快，是它一点犹豫都没有。
它不为难。
```

**用了什么：** P7 绝对理性第三方；"它不为难。"三字成段，是全文的情感重心——机器替人做了人做不到的拒绝。

## 转折点 — 打破重复句（R3 + E6）

```
她说，八千万，签字就行。
我说，让我想想。
她没有说话。我听见她那边有风。
```

**用了什么：** "我说行。"首次失守；"我听见她那边有风"——情感峰值处镜头转向无生命物（E6 转喻）。

```
我后来无数次回想过，那天她除了八千万还说了什么。风很大，柜子在响，我全记得，一个字不差。
我记不起来的是她的语气——她说"知道了"的时候，是抬着说的，还是放下的。
我想不起来。后来我就不想了。
```

**用了什么：** 记忆的选择性缺失作为创伤证据（E1）；"后来我就不想了"（R10）。

## 心碎的写法 — 全文最重处（E1 + E7）

```
我把手机扣在桌上，屏幕朝下。然后我做了一件事，到现在也不知道为什么：
我把两根手指按在手腕上，数了一下。
很稳。
又数了一遍，还是很稳。一分钟六十几下，和平时没有区别。
我坐在那儿，手还按在腕子上，像个护士在给别人量脉搏。
我想，原来是这样。
```

**用了什么：** E7 仪式性动作（数脉搏，数两遍）；"像个护士在给别人量脉搏"——最冷的一个明喻，用在自我分离的瞬间；"原来是这样"是唯一接近领悟的句子，且不解释领悟了什么。

```
我没有哭。我一直在等我哭。
```

**用了什么：** R10 否定句式的天花板形态。九个字。

## 尾声 — 反高潮（R12 + P4 + P5）

```
有一天我扣子又松了。想起抽屉里还有那个针线包，她留下的。
我拿出来缝了两针，不对。她说过线要顺着原来的针脚走，我忘了是哪边。
我把它放回去了。
我的大衣现在还是晃的。
```

**用了什么：** 物件回收（E2）：重逢失败——缝两针，不对，放回去；"我忘了是哪边"是全部的失去。

```
如果那天我签了，她还会打来吗。
我想了很久。
……
凌晨四点的车库，
一盏灯都没亮。
```

**用了什么：** R12 反高潮三步全齐；与开篇"已经有人替她付学费"构成时间回环；最后一行两个短句断行，落在空镜。

## 语感基准（自检时对照）

- 读完任何一节，情绪浓度应该低于信息浓度
- 每页至少一个"我花了钱但什么都没发生"的事实
- 每个情感峰值后紧跟一个物理动作或物件
- 全文的"疼"分布在至少 5 个不同物件上，从不落在同一处两次
