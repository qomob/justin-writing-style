# 反模式（Anti-Patterns）

> Critique 阶段逐条扫描。任何一条命中即标记，Revision 阶段必须修复。
> 每条带检测信号（怎么发现）与纠正方向（怎么改）。

## AP1 直接情感形容词（一票否决）

- **检测信号**：出现悲伤/痛苦/心碎/难过/绝望/幸福/快乐/伤心/激动/感动/心酸/温馨/温暖 等
- **语料对照**：原文 7000 字此类词出现 **0 次**
- **纠正方向**：删除形容词，替换为①一个数字（"我犹豫了三天"）②一个动作（"我把手机屏幕朝下"）③一句对话（"我说辛苦了"）

## AP2 解释性抒情 / 升华句（一票否决）

- **检测信号**："那一刻我明白了……""原来爱就是……""这件事教会我……""我才知道什么叫……"
- **纠正方向**：领悟降级为白描。参照原文的顿悟写法——"我想，原来是这样。"（信息量：零；杀伤力：满）

## AP3 AI 腔排比（一票否决）

- **检测信号**：一段之内三个以上结构相同的分句；"不是……而是……"出现；"有一种……叫……"出现
- **纠正方向**：保留事实最强的一条，其余删除。本风格的力量来自不对称——一个短句打碎一堆长句，而不是长句们齐步走

## AP4 情感节点上的长句

- **检测信号**：情绪转折处（告别/沉默/失去）句子超过 20 字
- **纠正方向**：拆分。拆不动就删——通常一半的字是"舍不得删的描述"，删掉后剩下的一半才是正文

## AP5 过渡词（检测即扣分）

- **检测信号**：然而 / 与此同时 / 不知不觉 / 时光荏苒 / 岁月如梭 / 后来我才明白 / 随着时间的推移
- **纠正方向**：全部删除，直接换行硬切。需要时间感就报日期

## AP6 比喻堆砌

- **检测信号**：每千字比喻超过 2 个；出现暖喻/通感喻（"像刀割一样""心里像被掏空"）
- **纠正方向**：按话题只留一个冷喻。喻体从这三个货架取：建筑物/制度（凡尔赛宫、王朝）、职业流程（医生做检查、核对年号）、工艺（一套很小的工具）

## AP7 引号对话 + 对话修饰（检测即扣分）

- **检测信号**：出现引号包裹的对白；出现"她幽幽地说 / 他叹了口气说 / 我喃喃自语"
- **纠正方向**：去引号，用"她说，""我说，"直陈。说话动词只允许：说、问、回答。语气副词全部删除

## AP8 心理描写（检测即扣分）

- **检测信号**："我心里五味杂陈 / 百感交集 / 说不出是什么滋味 / 脑子里一片空白"
- **纠正方向**：换成可观测的行为读数。"我数了一下，十一秒。""我把手放在胸口，数了一下。心跳很稳。"——身体数据替代心理状态

## AP9（警告级）叙述者评价他人

- **检测信号**：出现"她真是个……的人""他其实很可怜/可恨"
- **纠正方向**：删评价，留事实。读者对人物的全部判断必须来自人物自己的言行。原文对女主零评价——这正是全文争议性（读者分成两派）的来源，评价性写作会杀死这种张力

## AP10（警告级）全篇结构无回环

- **检测信号**：结尾意象与开头无任何呼应
- **纠正方向**：Revision 阶段检查：开头的数字/物件/场景是否在结尾回收？没有就在结尾补一次回收，用最短的一句
