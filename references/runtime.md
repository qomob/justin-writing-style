# Runtime：判断回路配置（Judge / Critique / Revision）

> 本文件定义从初稿到成品的判断回路。没有判断回路的风格 skill 只是提示词模板。
> 状态机：`draft → judge → critique → revise → (loop ≤ max_rounds) → final`

## 1. 判断维度（Judge Dimensions）

对初稿按五维打分（0-10），加权求和：

| # | 维度 | 权重 | 测量方法 | 否决线 |
|---|------|------|---------|--------|
| D1 | restraint 情感克制 | 0.25 | 扫描直接情感形容词数量（AP1）、升华句（AP2）、心理描写（AP8） | 形容词 >0 → 该维 0 分 |
| D2 | concreteness 具体度 | 0.25 | 数具体数字与专有物件出现密度；找连续 >100 字无数字/物件的段落 | 存在这种段落 → ≤4 分 |
| D3 | rhythm 节奏 | 0.20 | 抽查 3 个情感节点的句长（≤20 字？单句成段？）；统计短句占比感觉值 | 任一情感节点句 >20 字 → ≤4 分 |
| D4 | structure 结构装置 | 0.15 | 检查：冷开场？时间硬切？重复短语？物件回收？结尾回环？ | 缺 3 项以上 → ≤4 分 |
| D5 | deadpan 平叙荒诞 | 0.15 | 感叹号数量（=0？）；对特权/极端场景是否用了后勤视角；是否有叙述者评价 | 感叹号 >0 → 该维 0 分 |

**评分输出格式：**
```
D1 restraint:      8/10  （说明）
D2 concreteness:   7/10  （说明）
D3 rhythm:         9/10  （说明）
D4 structure:      6/10  （说明）
D5 deadpan:        8/10  （说明）
weighted_total:    7.6/10
```

- weighted_total ≥ 8.0 → 进入终检
- 6.0-7.9 → 进入 Revision
- < 6.0 → 返回重写（保留可复用的具体物件与对话素材，丢弃全部抒情段落）

## 2. Critique（诊断，不是重写）

Revision 前必须输出诊断报告，三条以内：

```
[Critique]
1. 位置：第 X 段 —— 命中 AP2（升华句"……"）→ 纠正：降级为白描
2. 位置：第 X 段 —— 连续 120 字无数字 → 纠正：把"很贵"换成具体价格
3. 位置：结尾 —— 未回收开头意象 → 纠正：补一句物件回收
```

规则：
- 诊断必须指向**具体位置 + 具体反模式 + 具体纠正动作**，禁止"整体可以更克制"这类无法执行的评语
- 一次 Critique 最多 5 条问题，按权重排序（D1/D2 问题优先）

## 3. Revision（修订，保护性局部修改）

- **max_rounds = 2**（普通篇幅 800-3000 字）；>3000 字的长文 = 3
- **diagnose_before_rewrite = true**（禁止无诊断重写）
- 修订规则：
  1. 只修改 Critique 标记的位置及其紧邻句
  2. 未标记的段落**原样保留**（preserve 保护——全篇重写 = 重新抽卡，revision gain 归零）
  3. 每轮修订后重跑 Judge，记录分数
- **Revision Gain = final_score − initial_score**
  - gain ≥ 1.0 → 判断回路有效
  - 0 < gain < 1.0 → 检查 Critique 是否太温和
  - gain ≤ 0 → **回滚**至修订前版本，重新诊断

## 4. Style Drift 防御（模糊修正请求）

用户说"再煽情一点 / 更有感染力 / 更高级 / 更有网感"时：

| 用户说 | 解释为 | 允许的手段 | 禁止的手段 |
|--------|--------|-----------|-----------|
| 再煽情一点 | emotional_explicitness +0.1 | 延长沉默节拍（多一个"我沉默了"）、延长数字（"我数到第十一秒"） | 加任何情感形容词 |
| 更华丽一点 | metaphor_density +0.5/千字 | 增加一个功能性冷喻 | 暖喻、通感、比喻排比 |
| 更有网感 | 时代物件更新 | 换用当代科技物件（AI 工具、社交平台细节） | 网络流行语、语气词、表情符号 |
| 更高级一点 | 抽象度 +0.05 | 结尾清零句更收敛 | 文学腔、翻译腔、诗化语言 |

**规则：模糊修正永远解释为指纹的局部参数调整，绝不整体重写风格。** 无法映射到参数的请求（"写得更狂野"），先向用户确认含义再动手。

## 5. Failure Memory（失败记忆）

运行中记录三类失败，供同会话后续创作回避：

1. **反复命中的反模式**（如每次都写升华句）→ 在初稿前主动声明"本次重点规避 AP2"
2. **用户否决记录**（"这段太用力了"）→ 标记该手法为禁区
3. **指纹漂移**（修订后反而更像普通 AI 文）→ 回滚并检查是否违反 preserve 规则

## 6. 快速自检清单（终检）

发布前逐项打勾：

- [ ] 全文情感形容词 = 0
- [ ] 全文感叹号 = 0
- [ ] 冷开场：两个并置事实，无背景交代
- [ ] 对话无引号、无修饰动词
- [ ] 数字密度：随手翻一页，100 字内必有数字或专有物件
- [ ] 至少一个重复短语作为节拍（≥3 次）
- [ ] 至少一个物件在结尾回收
- [ ] 结尾是清零句，无升华
- [ ] 时间全部硬切，零过渡词
- [ ] 叙述者对任何人零评价
- [ ] 全部人物/机构为虚构或化名，无真实人名与可识别真实对象
