# 风格规则手册（Style Rules）

> 完整句法与词汇规则，Step 4 分节生成时加载。每条规则附自创示范例证。
> 证据等级：句法 / 词汇 / 数字规则为 primary（源样本直接可观察）；例证均为自创示意，非原文摘录。

## R1 段落规则

单句成段是默认态。一段最多 3 句。超过 3 句必须拆分。

示范形态：

```
我说可以让司机去接。
她说不用。
她说，酒店问我，订金什么时候到。
```

**执行要点：** 写完一段后数句号。≥4 句即拆。拆分后的碎句不是 bug，是呼吸。

## R2 对话规则

- 对话不用引号
- 引导语固定为"她说，""我说，""我问，""她问"
- 对话动词只许"说 / 问"，禁"冷冷地说""轻声问""叹了口气说"等一切修饰
- 相邻多轮对话时引导语可省略，仅以换行区隔

```
她说，表停了怎么办。
我沉默了。她说，不管了，去吃饭吧。
我说行。
```

## R3 顺从性重复句

全文选定一个短句作为情感标记，机械重复 ≥5 次。它在转折点被打破，打破即叙事的断裂。

示范选择："我说行。"——全文出现 6 次以上，覆盖：包餐厅、订机票、付定金、转账、陪她回老家。打破点：

```
她说，八千万，签字就行。
我说，让我想想。
```

**执行要点：**
- 重复句必须是"顺从"语义，2-4 个字，无主语修饰
- 打破句与重复句结构对称（"我说行。"→"我说，让我想想。"）
- 打破只发生一次，之后不修复

## R4 零抒情

禁用词类清单：
- 情绪名词：难过、悲伤、心痛、幸福、孤独、绝望、心碎
- 情绪形容词：痛苦的、温柔的、残忍的（评价性使用）
- 心理动词直述：我感到、我意识到自己爱、我的内心

替代方案见 emotion-engineering.md 的情感转译表。

## R5 数字规则

- 一切量精确到个位或合理的细分单位
- 数字出现后绝不接感叹、评价、解释
- 时间也精确："下午7:10""犹豫了三天""缝了快四十分钟""数了三十秒"

```
2011年，那年冬天冷。我买了件外套，八百块。我记得这个价格，因为我犹豫了一个星期。
```

**执行要点：** 模糊量词（很多、好几天、几十万）是风格污染，逐个排查替换。

## R6 金钱的写法

钱只配操作动词：转、批、买、赔、递、付、垫。

```
两百万，定金。
我转了。
```

钱的句子必须与情绪句物理隔离——上一行"我转了"，下一行可以接无关的事（"过会儿，她把手机递过来给我看。"），绝不接心理活动。

## R7 词汇禁区

- 禁成语（四字格套语）
- 禁形容词连用（≥2 个形容词修饰同一名词即违规）
- 禁排比抒情
- 明喻全文 ≤3 处，且只许用于"物"或"动作"，不许用于情绪

明喻配额示范（全文仅 3 处的形态）：

```
像一套很小的工具。
像两支军队在核对番号。
像讨论一门手艺。
```

## R8 说明性长段

超过 4 行的长段是稀缺资源，只许分配给：物的技术细节、流程、行业知识。对人永远短句。

示范的三个长段可分别给：养护方法论（红木柜垫报纸、留缝散味）、车辆使用说明（十二缸车拉高速清积碳）、医疗 / 法务流程（预约窗口期、空腹、复查节奏）。

**执行要点：** 这种分配本身就是表达——对物的耐心精确，对照对人的失语。长段里的旁人（家政、司机、管家）越尽职，主角的关系越空。

## R9 专有名词不解释

型号、地名、术语、行话直接使用，不注释、不翻译、不铺垫。

```
和那套公寓一起空着的，还有辆迈巴赫停在负二层，司机每天照常来打卡。
岛上的规矩是no news, no shoes。
```

## R10 否定句式

用"没有 + 动作"表达克制与留白：

```
我没有说。
我没有问。
我没有哭。我一直在等我哭。
中间我没提，虽然我知道。
```

**执行要点：** "没有做的动作"信息量大于做了的动作。在关键场景后补一句"我没有……"。

## R11 悖论并置

两个矛盾陈述相邻放置，中间零解释：

```
她说的话我全信。
那条语音我存着，一直存到现在。
但是我一个字也不信。
```

```
我以为她不愿意。我把手收回来，准备说点什么。
她没说话。
```

## R12 结尾反高潮

三步走：
1. 明确写出核心问题（不回答）
2. 一次无效的求解尝试（"我想了很久。"）
3. 转向空镜 / 无人称场景收尾

```
如果那天我签了，她还会打来吗。
我想了很久。
……
凌晨四点的车库，
一盏灯都没亮。
```

**禁止：** 回答问题、升华主题、点题、抒情收尾、"后来我才明白"句式。
